1. Dashboard

The dashboard is the main page after login. It provides an overview of organizational performance through KPI cards and important alerts.

  • KPI Cards: Employee count, tags, evaluations, last backup, total leave days, average per employee, upcoming leaves, percentage who took leave, top department, remaining holidays this month, sick leaves, employees with no leave, annual absence rate, oldest employee.
  • Alerts: Unprocessed year warning, contracts ending within 30 days, unconverted delay hours, unusual leave patterns.
  • Quick Actions: Export CSV/Excel, Import Excel, manual backup, import classifications/criteria, reset balances, wizard mode.

2. Employee Management

Complete employee data management with dynamic customizable fields.

  • Employee List: Tabular view with advanced search, filtering by tags, department, classification, age, hire date, sorting, bulk edit (department, classification, tags).
  • Add/Edit Employee: Form divided into sections (basic info, additional details, administrative info, other info). Includes all required fields: job number, name, father name, mother name, birth date, gender, nationality, disability, blood type, marital status, national ID, phone, hire date, education, Sham Cash account, job category, appointment status, workplace, department, classification, target service years, contract end date, uncompensated absence days, tags.
  • Tags: Flexible employee classification, used for filtering and grouping.
  • Service Calculator: Automatically calculates from work periods, allows manual addition, deducts uncompensated days, sets target service, calculates expected completion date.
  • ID Card: Generates a card with QR code containing basic employee data, printable.
  • Import/Export Employees: Export CSV, JSON, Excel. Import from Excel with column mapping, supports update/insert by job number.
  • Soft Delete: Employees are moved to "Deleted Employees" list, can be restored.

3. Leave Management

  • Leave Types: Customizable (Administrative, Unpaid, Paid Sick, Unpaid Sick, Maternity, Unexcused, Lateness (3 hours), Hourly Leave). Each type has hours per day and yearly flag.
  • Entitlements: Default per classification, with individual override per employee. Year reset without carryover.
  • Individual Leave Registration: Quick form with employee search, leave type, dates, hours (for lateness/hourly), automatic day calculation excluding Fridays and holidays. If type empty, default is used.
  • Bulk Leave Registration: Register leave for groups based on tags or classifications.
  • Calendar: Monthly leave view with drag‑and‑drop to modify dates, filtering by employee/department, print button.
  • Team Calendar: View department team leaves.
  • Public Holidays: Add fixed (yearly) or variable (manual) holidays.
  • Lateness to Leave Conversion: Automatic conversion of accumulated hours to regular leave according to priorities.

4. Evaluations

  • Evaluation Criteria: General or classification‑specific, with descriptions for each score (1‑5).
  • General Evaluation Form: Select employee, evaluator name, date, assign scores (1‑5) per criterion, saved with radar chart display.
  • View Evaluations: Each employee has a page showing all previous evaluations with radar charts.
  • Import Evaluation Results: Upload Excel or CSV file with columns "Job Number", "Evaluation Date", "Evaluator Name", and criterion columns. Preview and map columns before import.
  • Delete Evaluation: Can delete any existing evaluation.

5. Reports

  • Individual Employee Report: Shows basic data, current leave balances, leave log. Export to PDF and Word (docx).
  • Monthly Leave Report Export: Select month, export CSV or JSON.
  • Full Database Export: Export all tables as JSON (complete backup).

6. Settings & Maintenance

  • Classifications: Add/delete job classifications (Doctor, Nurse, Admin...).
  • Default Entitlements per Classification: Set default days per leave type for each classification.
  • Leave Types: Add/edit/delete leave types with hours per day and yearly flag.
  • Departments: Manage departments (add, edit, delete).
  • Public Holidays: Add fixed (yearly) or variable (specific date) holidays.
  • User & Role Management (admin only): Roles: admin, registerar, supervisor, viewer with different permissions.
  • Backups: Manual button in dashboard and automatic every 7 days (keeps last 4 copies). Restore from JSON file.
  • Year Start Processing: Creates entitlements for next year (no carryover).
  • Reset Balances: Reset current year entitlements to classification defaults.
  • Import Classifications & Criteria from text files: Button in dashboard to import from classifications.txt, evaluation_criteria.txt, etc.

7. Smart Holidays

Create rules for recurring holidays not based on fixed dates, such as:

  • Weekday: e.g., every Thursday (value 4).
  • Day of month: e.g., days 1,15 of each month.
  • Formula: e.g., "last Friday of month" or "first Monday of month".
  • Rules can be restricted to specific departments or classifications.
  • Preview holidays for current year to verify rules.

These rules are used in leave day calculation (smart holidays are not counted as work days).

8. Wizard Mode (Demo Data)

Creates 10 demo employees with random leaves, tags, classifications, departments. Used for testing or demonstrations.

  • Start Demo Session: Adds 10 demo employees and stores their IDs in session.
  • Cleanup Demo Data: Deletes all employees created by the wizard.
  • Interactive Demo Mode: Separate version for easier cleanup.

9. Custom Themes

You can change the entire system appearance with 9 different themes:

  • Default (Blue)
  • Medical (Green)
  • Night (Dark)
  • Pastel
  • Light Day
  • Sunset
  • Ocean
  • Amber
  • Lavender

Selected theme is saved in the browser and applied automatically on return. Auto dark mode based on device time can be enabled from user settings.

10. Import & Export

  • Export Employees: CSV, JSON, Excel.
  • Monthly Leave Report Export: CSV, JSON.
  • Full Database Export: JSON (full backup).
  • Import Employees: From Excel (xlsx) with column mapping, support update/insert by job number.
  • Import General Evaluation Results: From Excel or CSV, with column mapping and validation.
  • Import Classifications and Criteria: From text files (classifications.txt, evaluation_criteria.txt, etc.) via settings button.
  • Full Database Import: Upload JSON file to restore previous backup (full replacement).

This manual serves as a complete reference for all available system functions. For additional inquiries, please contact the system administrator.
